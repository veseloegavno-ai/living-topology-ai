# living-topology-ai
Experimental self-growing fractal AI architecture based on NumPy and OpenCV.


## 🚀 Быстрый запуск / Quick Start

### 1. Клонирование репозитория и подготовка
Убедитесь, что у вас установлен Python 3.10+. Система автоматически проверит и установит необходимые зависимости при первом запуске (`opencv-python`, `sounddevice`, `pyttsx3`, `docx2txt`, `psutil`).

### 2. Запуск монолита
Запустите терминал в папке с проектом и выполните:
```bash
python core.py
```

### 3. Управление системой в режиме реального времени
* **Режим бодрствования:** Модель непрерывно анализирует видеопоток с камеры (геометрия Собеля) и акустический спектр Фурье.
* **Интерактивный чат:** Вводите текст прямо в консоль для общения с кристаллом памяти.
* **Ассимиляция знаний:** Используйте команду `/read путь_к_файлу.txt` или `.docx`, чтобы запустить фрактальное чтение и однопроходное обучение по Хеббу.
* **Аварийная эвакуация:** При заполнении RAM на 90% от лимита, вставьте USB-накопитель. Система автоматически эвакуирует синаптические кристаллы (`crystals.pkl`) на внешнюю флешку.
